## 从自己的门店，找到可以讲的内容

一条有用的门店视频，常常来自一个普通的细节：产品怎样做出来，老板为什么选择一种食材，服务过程里有什么讲究，或者顾客每天会问什么问题。

这个项目把这些素材放进一套本地工作流程：先整理老板与门店的表达底稿，再归类已有镜头，选择拍摄结构，编排镜头与字幕，最后把可复用的模板用于下一次生产。

这是基于原 Windows 0.2.0 项目整理的脱敏社区版。商业激活与机器码绑定已移除；独立的本地 API 令牌保护、Electron 沙箱、上下文隔离和安全存储接口继续保留。社区版使用独立的应用标识与数据目录，原商业项目保持不变。

## 四步，把一个门店故事做成发布资料

| 步骤 | 工作台模块 | 你可以做什么 |
|---|---|---|
| 01 | 人设档案 | 写清老板、门店、顾客、故事和说话风格 |
| 02 | 素材中心 | 扫描自己选择的目录，整理图片与视频，不搬走原文件 |
| 03 | 剪辑工坊 | 编排镜头、时长、字幕、标题与背景音乐，合成竖屏视频 |
| 04 | 发布中心 | 准备成片、标题与话题，再去官方创作者平台完成发布 |

**当前是发布辅助，不是无人值守代发。** 平台登录与最终发布由使用者确认，不随源码收集或分发平台密码、Cookie，也不宣传已实现全平台自动发布。

## 当前可以做什么？

- **本地素材整理：** 扫描选择的目录，预览支持的媒体并保存分类；原文件保持在原位置。
- **竖屏真实合成：** 通过 FFmpeg 输出视频，支持 720P/1080P 设置、标题、字幕和可选背景音乐。
- **剪辑模板复用：** 保存镜头计划与参数，供下一次制作使用。
- **批量生产：** 通过 FFmpeg 队列执行保存的模板，记录进度和失败原因。
- **可选 AI 文案：** 使用自己的百炼兼容服务账号生成脚本。请求会发送给服务商，服务费用与数据政策以账号配置为准；Electron 使用 safeStorage 保存配置密钥。
- **发布资料准备：** 整理作品、标题、话题和计划，提供配置好的官方创作者平台入口。最终提交由人完成。

应用界面目前为中文。顶部语言按钮只切换项目介绍，不切换运行时界面语言。

## 开始运行

准备 **Windows、Python 3.11、Node.js 22.12 或更高版本，以及 PATH 中可调用的 FFmpeg/ffprobe**。视频工具可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html) 获取。源码仓库不附运行库或安装器二进制。

下载并解压 [审核后的完整源码包](./storefront-media-agent-source.zip)，或在完整 Git 目录可用时使用仓库源码。在源码根目录的 PowerShell 中执行：

```powershell
python -m venv .venv
.venv/Scripts/python -m pip install -r src/backend/requirements-dev.txt
npm ci
npm ci --prefix src/frontend
npm run dev
```

桌面外壳会启动本地后端，寻找可用的回环端口，并向界面传入随机本地令牌。脱离 Electron 的开发后端不是生产网络服务。

### 运行源码检查

```powershell
.venv/Scripts/python -m pytest -q
npm run build:renderer
node --check src/electron/main.js
```

后端测试使用隔离数据。真实 FFmpeg 测试会生成两段纯色镜头，加标题和字幕合成，并检查输出视频流为可播放的 720×1280。

### 构建 Windows 安装包

```powershell
.venv/Scripts/python scripts/build.py
```

脚本准备前端与冻结后端，并要求本地 FFmpeg 运行库附带许可文件。若要分发安装器，需要检查实际运行库的许可及对应源码要求，详见 [第三方说明](./NOTICE.md)。社区版尚未验收签名安装器、升级迁移或真实 AI 服务。

## 技术结构

| 组件 | 技术 | 职责 |
|---|---|---|
| 桌面外壳 | Electron | 窗口、原生文件选择、本地服务启动、安全配置与外链白名单 |
| 操作界面 | Vue 3、Element Plus | 经营台、人设、素材、时间线、批量队列与发布准备 |
| 后端 | FastAPI、aiosqlite | 本地 API、记录、合成任务和可选文案请求 |
| 媒体引擎 | FFmpeg、ffprobe | 素材探测、镜头处理、字幕和最终合成 |
