# Public source scope

This repository is a sanitized MIT community edition based on the supplied Windows 0.2.0 project. The original project folder is unchanged.

Included: Electron shell, Vue interface, FastAPI backend, procedural icon assets, portable build helpers and isolated automated tests.

Excluded: original Git history, dependencies, build outputs, runtimes, installers, actual databases, customer media, logs, secure storage files, API keys, platform credentials, commercial signing material and private operator tooling.

Community changes: remove commercial activation/machine tracking; retain local API-token protection and Electron security; use a separate community app identity and data namespace; return generic provider error messages without reflecting a provider response body; use public-registry lockfile URLs.

UI previews use a fictional cafe profile and an unfilled industry shot plan. They are not real customer work or evidence of AI/provider acceptance. No real platform posting was performed.
