# Demo images

The application icon is generated by `scripts/generate_assets.py` from geometric shapes and is included under MIT.

Screenshots were captured from the community source with a fictional store profile and sample industry shot plan. There are no customer photographs, real account credentials, original database records or genuine marketing-performance claims in these previews. The shot plan still requires the user's own footage; it is not a finished campaign.

Generated FFmpeg test clips contain solid colors, not customer media. Users remain responsible for rights to their own photos, videos, voices and music.
