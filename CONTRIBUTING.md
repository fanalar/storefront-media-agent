# Contributing

Small, reproducible improvements are welcome: media-format handling, timeline interaction, batch failure recovery, subtitle layout, accessibility, English UI localization and publishing preparation.

Use synthetic footage and fictional store/customer details in examples. Describe the version, platform, reproduction steps, expected behavior and actual result. Do not automate a platform's final publish action or introduce stored platform passwords/cookies.

Run the frontend build and relevant backend tests. Changes to video composition should include a real FFmpeg output check. Keep `README.md` and `README.zh-CN.md` in sync when changing public capabilities or setup steps.
